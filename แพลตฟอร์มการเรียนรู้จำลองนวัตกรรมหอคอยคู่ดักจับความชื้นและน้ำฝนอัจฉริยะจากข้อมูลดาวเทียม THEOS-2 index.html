น้ำจืด
น้ำทะเล

สถานะการตั้งค่า

1) ใส่ Sphere API Key ใน <script src> บรรทัดบนสุดของไฟล์
2) ใส่ชื่อ layer จริงของแนวปะการังใน CONFIG.CORAL_TYPENAME
3) ใส่ Open Data API Key ใน CONFIG.OPENDATA_API_KEY

ชั้นข้อมูล

คลิกบนแผนที่เพื่อปักหมุด "แหล่งน้ำจืด" แล้วระบบจะคำนวณระยะห่างถึงแนวปะการังที่ใกล้ที่สุดให้อัตโนมัติ

กำลังโหลดแผนที่…
